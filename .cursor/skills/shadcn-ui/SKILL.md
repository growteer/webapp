# shadcn-ui skill

## When to use
- Any task involving new UI components, pages, dialogs, forms, tables, dashboards, navigation, styling refactors.

## Procedure
1) Confirm MCP availability:
   - If `shadcn` MCP is not connected, say so and suggest enabling it.
2) Planning:
   - Use MCP to browse/search registry items that match the request.
   - Propose a component list (exact names) + composition plan.
3) Implementation:
   - Install chosen components via MCP.
   - Compose them; do not invent props/variants.
4) Close-out:
   - List installed registry items and touched files.
